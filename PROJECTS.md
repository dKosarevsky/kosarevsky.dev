# Editorial sources

Reviewed on 2026-10-20. The collection is deliberately small. All six repositories are public and unarchived in the connected GitHub account. Repository descriptions and source files inform the copy; no popularity figures or unsupported performance claims appear on the site.

| Project | Source | Reason for inclusion |
| --- | --- | --- |
| AI Talks | [README](https://github.com/dKosarevsky/AI-Talks/blob/main/README.md) | Established, pinned Streamlit interface to the ChatGPT API. Link to source because the documented hosted demo redirected to Streamlit authentication during the check. |
| Spherical Snake | [README](https://github.com/dKosarevsky/spherical-snake/blob/main/README.md) | A small Streamlit/pygame game rendered on a sphere. Its repository advertises `https://spherical-snake.streamlit.app`. |
| Video Downloader | [Repository](https://github.com/dKosarevsky/video_downloader), [public profile](https://github.com/dKosarevsky) | A pinned, focused utility; the profile advertises `https://video-loader.streamlit.app`. |
| ajpegli | [README](https://github.com/dKosarevsky/ajpegli/blob/main/README.md) | JPEG-to-NumPy loading with Google jpegli and a documented stable Python API. No claim of being faster than alternatives. |
| albu-tta | [README](https://github.com/dKosarevsky/albu-tta/blob/main/README.md) | Research into learned test-time augmentation. Explicitly described as experiments, not as validated accuracy gains or a finished hosted product. |
| albu-mcp | [README](https://github.com/dKosarevsky/albu-mcp/blob/main/README.md) | MCP server for augmentation previews, visual feedback and reproducible pipeline export. |

Hackathon work, coursework and generic forks are outside this collection. `starship-janitor` was excluded because the repository was empty at review time. No projects have been invented to fill the grid.

The two Streamlit destinations could not be runtime-verified from this environment. They are published project URLs, not a claim that their hosted apps are awake or healthy. Each card also offers a GitHub source link.

## Updating

Edit `assets/projects.js` to change the selected work and its English, Russian and Spanish descriptions. Update `assets/i18n.js` for interface copy. The homepage defaults to English on first visit, remembers an explicit language choice, and accepts `?lang=ru` and `?lang=es`.

The card artwork is an original abstract illustration, not a screenshot of the linked product.
