| Project | Source | Destination and editorial scope |

A MOVE AGO, Agent Architecture, microgpt-fortran and Teleport Research are the four featured entries. A MOVE AGO, Agent Architecture and Salvo have preview-image paths in the project data. The two private projects use local abstract artwork rather than screenshots. Public projects retain their source links; Aximo's primary link opens an interactive API demo, while albu-mcp and ajpegli link directly to their repositories.

Fresh GitHub metadata checked for this selection marks both microgpt-fortran and Teleport Research as private. Their cards must not expose repository URLs, source buttons, demo buttons or full private documentation unless the owner later changes that decision. Keep microgpt-fortran's description specific to its current small model and short-name task; do not present it as a general-purpose chatbot. Keep Teleport Research's description at the research-planning stage and avoid claims of a breakthrough or experimental success.
